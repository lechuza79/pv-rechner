# Herzberg balcony funding: correction of existing combination claim

Reviewed 17 September 2026. This corrects our existing description, not a newly enacted municipal change.

[Official programme page](https://www.herzberg.de/service/themen/klima-und-umwelt/klimaschutz/foerderung-balkonkraftwerke/?vs=1) and linked three-page guideline dated 18 September 2025 read in full. The ordinary catalogue URL currently displays an election landing page. Its own onward link with `?vs=1` exposes the programme normally; no access-control bypass. Full HTML, PDF and retrieval manifest retained in the local watcher archive.

The municipality still offers up to EUR100 for a new balcony installation and an application form. No closure is established; the remaining budget is not independently known. Keep the existing status and calculation amount.

Section 3 excludes measures already supported by other funding, with federal/state programmes as examples. The application form also requires disclosure of other funding and subsequent changes. No specific KfW270 exception was found. The existing `BUND` reference generated positive KfW270 and VAT zero-rate combination badges. Remove that unsupported blanket positive statement using an empty combination list. This is not a tax-law finding that the VAT zero rate is prohibited and must not be described as one.

Section 4.3 expressly permits either funding approval or approved early commencement before starting. Application alone does not authorise commencement. Correct the absolute wording to retain this exception; acceptance of an offer, order or contract already counts as commencement.

Three independent Council reviewers, including adversarial review, agree; the separate Legal-Judge confirms the narrow correction. One judge's direct PDF attempt was blocked; it reviewed the independently saved original instead, not a fictitious second successful retrieval.
