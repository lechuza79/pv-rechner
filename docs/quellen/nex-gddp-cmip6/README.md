# NASA NEX-GDDP-CMIP6 — Lizenzbelege (abgelegt 18.09.2026)

Quelle der Klimaprojektion im Klimaanlagen-Rechner (`lib/klima-projektion.ts`,
gebaut von `scripts/klima-projektion-build.ts`).

- `CMIP6_source_id_licenses_2026-09-18.html` — CMIP6-Lizenzliste. Alle acht
  verwendeten Modelle stehen dort unter **CC BY 4.0**, jeweils mit Datum der
  Lockerung (2022-06-02 bis 2022-08-07, vorher CC BY-SA bzw. CC BY-NC-SA).
- `PCMDI_TermsOfUse6-2_2026-09-18.html` — CMIP6-Nutzungsbedingungen 6-2: die
  Lizenzliste geht der `license`-Angabe im Dateikopf vor; Danksagungstext.
- `NEX-GDDP-CMIP6-Tech_Note_Rev5.pdf` — NASA Tech Note, Abschnitt 0: CC0 für die
  NASA-Schicht, ursprünglich CC BY-SA „as noted in the metadata of each file".

Die heruntergeladenen Dateien (v2.0, erzeugt Nov. 2024) tragen im Kopf noch
`cmip6_license = CC-BY-SA 4.0` — überholter Altbestand, siehe Lizenzliste.

Rechtliche Einordnung: zwei Legal-Judges am 18.09.2026 (der zweite adversarial).
Tragend ist CC BY 4.0 je Modellgruppe, nicht NASAs CC0. Pflicht: Nennung mit
Lizenzlink und Änderungshinweis, WCRP-Danksagung, Modellliste, Kennzeichnung als
Modellprojektion ohne Gewähr — umgesetzt im Eintrag `nexGddp` in
`lib/data-sources.ts`.

Offen (Außenkontakt, Entscheidung des Betreibers): kurze Anfrage an NASA NCCS
zur Lizenz der Fassung 2.0 und an eine Modellgruppe zur Bestätigung der Lockerung.
